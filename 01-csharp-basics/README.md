# Практична робота №1. Базові конструкції C#. Консольний застосунок

**Модуль:** 1 — огляд та повторення C#
**Тип застосунку:** консольний (.NET, Console App)
**Обсяг:** 2 год аудиторних + СРС

## Мета роботи

Закріпити навички роботи з базовими типами даних, операторами, керуючими конструкціями (розгалуження, цикли), масивами та методами мови C#; навчитися організовувати консольний діалог введення/виведення даних.

## Завдання

- Створити консольний проєкт (.NET 10, Console App) у Visual Studio / Rider / VS Code з назвою виду Lab1_<Прізвище>.
- Реалізувати введення вихідних даних з клавіатури (консолі) з перевіркою коректності введення (обробка невірного формату без завершення програми аварійно).
- Реалізувати обчислення/оброблення даних відповідно до свого варіанта завдання, використовуючи щонайменше: умовний оператор або switch, цикл (for/while/foreach), одновимірний або двовимірний масив, щонайменше 2 власні методи (з параметрами та поверненим значенням).
- Реалізувати вивід результатів у зручному, форматованому вигляді (вирівнювання, заголовки таблиць у консолі).
- Передбачити просте меню (цикл з вибором пункту), що дозволяє повторювати обчислення без перезапуску програми, до вибору пункту «Вихід».

## Теоретичні відомості (стисло)

Типи даних (value/reference types), літерали, оператори та їх пріоритет, конструкції розгалуження (if/else, switch/switch expression), цикли (for, while, do-while, foreach), масиви, методи та їх сигнатури, базові засоби введення/виведення (Console.ReadLine/WriteLine), форматування рядків (інтерполяція, композитне форматування).

## Порядок виконання

1. Створити та налаштувати проєкт, перевірити компіляцію та запуск «порожньої» програми.
2. Спроєктувати структуру меню консольного застосунку.
3. Реалізувати введення даних з валідацією (TryParse, цикли повторного введення).
4. Реалізувати основний алгоритм обробки даних згідно з варіантом, винести логіку у методи.
5. Реалізувати виведення результатів та тестування на межових і некоректних вхідних даних.
6. Оформити код (іменування, коментарі), завантажити у Git-репозиторій.
