## Вибір варіанта завдання

У роботах, що містять кілька варіантів завдань, номер варіанта визначається порядковим номером студента в списку групи (за журналом/семестровою відомістю). Якщо кількість студентів більша за кількість варіантів у конкретній роботі, нумерація повторюється по колу. Кількість варіантів своя для кожної практичної роботи (4 або 6) — див. розділ «Варіанти завдань» у відповідному README.
