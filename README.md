# Документація до дисципліни «Розробка проєктів засобами платформи .NET»

Спеціальність 121, 3 курс

Репозиторій містить методичні матеріали дисципліни: практичні роботи (готові) та лекційні матеріали (буде додано окремо). Кожен матеріал існує як окрема папка з власним `README.md` — це джерело правди; сайт (MkDocs) збирає їх у зручну для читання й навігації документацію.

## Як користуватись

- Почніть з [00-setup](./00-setup) — гайд по налаштуванню робочого середовища для виконання практичних робіт, який включає встановлення dotnet-sdk, IDE (Visual Studio/Rider/VS Code) та поради по роботі з Git.
- **ПР №1–4** (Модуль 1) — окремі самостійні консольні застосунки C#/.NET, кожна робота в окремому проєкті.
- **ПР №5–8** (Модуль 2) — єдиний наскрізний мікропроєкт (Web API на ASP.NET Core + EF Core + SQLite), що нарощується від роботи до роботи в межах одного проєкту/репозиторію. Домен обирається один раз у ПР №5 (за таблицею варіантів) і використовується без змін у ПР №6–8.
- **lectures/** — місце для лекційних матеріалів, які додаються незалежно від практичних робіт.

## Документаційний сайт (MkDocs)

Матеріали також публікуються як сайт (`mkdocs.yml`, вихідні файли в `site-docs/`). Верхнє меню сайту має чотири розділи:

- **Головна** — `index.md`.
- **Налаштування середовища** — гайд `00-setup`.
- **Практичні роботи** — усі ПР №1–8, зібрані в один документ (`site-docs/practs.md`) для наскрізного читання/пошуку.
- **Лекції** — сторінка `site-docs/lectures.md`, наразі заглушка під майбутні лекційні матеріали.

Кожна сторінка сайту лише підключає відповідний `README.md` через `pymdownx.snippets` — редагувати вміст потрібно в папці роботи, а не в `site-docs/`.
